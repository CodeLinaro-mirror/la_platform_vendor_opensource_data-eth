qps615 contains ethernet mac device

Required properties:

- qcom,not-need-pinctrl: A boolean flag indicating if using pinctrl to set GPIO default status.
- qcom,phy-port-interface: This value indicates the type of MII between MAC and PHY.
                           Current values of src are:
							0 = ENABLE_USXGMII_INTERFACE
							1 = ENABLE_XFI_INTERFACE
							2 = ENABLE_RGMII_INTERFACE
							3 = ENABLE_SGMII_INTERFACE
							4 = ENABLE_2500BASE_X_INTERFACE

- qcom,phy-built-in-wol: A boolean flag indicating if the phy device has a built-in wol interrupt.
- qcom,phy-rst-gpio: reset gpio setting of phy device.
- qcom,phy-rst-delay-us: the reset delay time for keeping low level.
- qcom,phy-rst-settling-delay-us: wait time before accessing the phy register after phy reset.
- qcom,phy-reverse-rst: A boolean flag indicating if the phy reset level need reverse.
- phy-supply: enable phy power for phy device.

Example:

RLT8211 connected to port1:

&pcie1_rp {
	#address-cells = <5>;
	#size-cells = <0>;

	/* BDF 1.0.0 */
	pcie1_bus1_dev0_fn0: pcie1-bus1-dev0-fn0 {
		reg = <0x0 0x0 0x0 0x0 0x0>;

		/* BDF 2.3.0 */
		pcie1_bus2_dev3_fn0: pcie1-bus2-dev3-fn0 {
			reg = <0x1800 0x0 0x0 0x0 0x0>;
			qps615_rlt8211_eth1,qps615-rlt8211-eth1@pcie1_rp {
				reg = <0x100 0x0 0x0 0x0 0x0>;
				qcom,not-need-pinctrl;
				qcom,phy-port-interface = <2>;
				/* phy intn_wol int */
				qcom,phy-built-in-wol;

				/* phy reset*/
				qcom,phy-rst-gpio = <1>;
				qcom,phy-rst-delay-us = <10000>;
				qcom,phy-rst-settling-delay-us = <30000>;
				qcom,phy-reverse-rst;

				/* power enable*/
				phy-supply = <&ethernet_phy_vreg>;
			};
		};
	};
};
